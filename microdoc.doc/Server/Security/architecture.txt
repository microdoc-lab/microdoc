# Security protection on Server
Cover all protected methods of controller with `[Authorize]` attribute.

## Domain level security checks
Use `SecurityExtensions.IsInRole` in all controller methods that has no document context.

/code: if (!User.IsInRole(_domainOptions, "r", domain))
	return Forbid();

## Document level security checks
Use `SecurityExtensions.IsInRole` in all controller methods that has document context.

/code: if (!User.IsInRole(_domainOptions, "r", domain, documentId))
	return Forbid();
