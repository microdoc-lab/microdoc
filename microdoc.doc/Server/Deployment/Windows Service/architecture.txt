# Running as a Windows Service

## Register Windows Service
Run `Deploy\ServiceCreate.cmd` to create a service

## Testing without Https
In appsettings.json use following setting
`"Urls": "http://localhost:7273",`


## /code: Configure Certificates
// in appsettings.json add following section

  "Kestrel": {
    "Endpoints": {
      "Https": {
        "Url": "https://localhost:7273",
        "Certificate": {
          "Path": "C:\\Certificates\\server.pfx",
          "Password": "your-password"
        }
      }
    }
  }
