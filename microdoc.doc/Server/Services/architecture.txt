# Services
Server functionality is implemented in services:
- TagService - work with Tags
- DocService - work with Documents
- LockManager - distributed locking
- TagMoveService - track links after Tag renames (experimental)

# Configuration
Server configuration:
- class `MicroDocOptions` represent access to `appsettings.json`
  - logging
  - Google authentication
  - path to DomainOptions.ini
- class `DomainOptions` represent access to `DomainOptions.ini`
  - domains
  - users
