# Web Server
MicroDoc server implemented as ASP.NET Core application using net11.0 framework.
Standard components are used:
- dependency injection
- logging

## Used packages
- Microsoft.AspNetCore.Authentication.Google - Google authentication
- Microsoft.AspNetCore.Mvc.Razor.RuntimeCompilation - runtime view compilation
- Microsoft.Extensions.Hosting.WindowsServices - host server as Windows service
- Karambolo.Extensions.Logging.File - logging into file
- RecursiveAI.OneImage - create image thumbnails
- YamlDotNet - read/write Domain Options configuration; view.ini
